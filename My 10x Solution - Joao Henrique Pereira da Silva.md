# My 10x Solution: EuroGuard AI

## Executive Summary
EuroGuard AI is a production-ready, full-stack Retrieval-Augmented Generation (RAG) system engineered to assist legal, technology, and compliance teams in evaluating adherence to European digital regulations—specifically the **General Data Protection Regulation (GDPR)** and the **EU Artificial Intelligence Act (EU AI Act)**.

The solution pairs an enterprise-grade vector database architecture (PostgreSQL + `pgvector` hosted via Podman) with a high-performance REST API (FastAPI) and an intuitive web chat interface (Streamlit), powered by Google's `Gemini 3.6 Flash` and `gemini-embedding-001` models.

---

## Architectural Breakthroughs & "10x" Value Drivers

### 1. Zero-Hallucination Regulatory Grounding
Standard LLMs frequently hallucinate legal interpretations or confuse regulatory frameworks. EuroGuard AI solves this by strictly constraining prompt contexts to relevant vector chunks retrieved from PostgreSQL. If a user query falls outside the retrieved context, system guardrails prevent speculative answers.

### 2. High-Resilience API Strategy
To withstand LLM API rate limits, transient network outages, and 503 unavailability errors during peak demand, the backend utilizes `tenacity` retry logic with targeted exception filtering and fast backoffs, ensuring seamless user experience without HTTP timeouts.

### 3. Containerized & Portable Infrastructure
By encapsulating the PostgreSQL `pgvector` database inside a Podman container environment (`docker-compose.yml` / `Containerfile`), the system achieves complete environment isolation, reproducible local setup, and seamless cloud migration capabilities.

---

## Technical Stack & Component Breakdown

* **FastAPI Backend:** Provides validated, asynchronous REST endpoints (`/api/v1/query`) with Pydantic request/response schemas, CORS middleware, and automated OpenAPI (Swagger) documentation.
* **Streamlit Frontend:** Delivers a responsive, stateful chat interface connected to the FastAPI service with a 60-second client timeout window to accommodate automated model retries.
* **pgvector Search Engine:** Executes high-speed cosine similarity searches (`<=>`) directly within PostgreSQL 16 over 768-dimensional text embeddings generated by `gemini-embedding-001`.
* **SQLAlchemy ORM:** Manages session-scoped database connections, transaction safety, and schema declarations for regulatory chunks.

---

## Verification & Compliance Metrics

* **GDPR Analysis:** Accurately extracts consent requirements under Article 6(1)(a) and legal processing parameters.
* **EU AI Act Validation:** Correctly retrieves high-risk AI data governance rules under Article 10 without mixing non-regulatory context.
* **Guardrail Enforcement:** Successfully rejects non-regulatory queries (e.g., general knowledge questions) by confirming the absence of relevant information in the knowledge base.
